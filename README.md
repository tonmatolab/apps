# ミニアプリ集

小さなアプリを量産 → X / Instagram で発信 → アフィリエイトで収益化、のための置き場です。

## 構成

```
apps/
  index.html            … アプリ一覧（インスタのプロフィールリンクにはここを貼る）
  coffee-shindan/       … 1アプリ = 1フォルダ（index.html 1枚で完結）
    index.html
    og.html / og.png    … シェア時に出るサムネ（1200x630）
  tools/make-og.sh      … og.html → og.png を書き出す
```

## 新しいアプリを作る流れ

1. Claude に「◯◯診断を作って」と頼む（既存アプリと同じ型で作ります）
2. `bash tools/make-og.sh <フォルダ名>` でサムネ画像を作る
3. `index.html`（一覧）に1ブロック追加
4. GitHub に push → 数分で公開
5. X / インスタに投稿（下のテンプレ）

ローカル確認: `npx -y http-server . -p 5173` → http://localhost:5173

## 公開（GitHub Pages）

初回だけ:
1. GitHub で `apps` という公開リポジトリを作る
2. このフォルダを push
3. リポジトリの Settings → Pages → Branch: `main` / `/(root)` を選んで Save
4. 公開URL: https://tonmatolab.github.io/apps/ （新アプリの OGP には絶対URLを書く）

## 投稿テンプレ

**X（URL付き・サムネが出る）**
```
☕ コーヒータイプ診断を作りました
8問・1分で、あなたにぴったりの1杯がわかります

私は「癒しのカフェラテタイプ」でした🤍
みんなは何タイプ？👇
<URL>
#コーヒータイプ診断 #診断メーカー #個人開発
```

**Instagram（リンクが貼れないので画像＋プロフィール誘導）**
- 結果画像（アプリの「結果画像を保存」で出る 1080x1350）を全タイプ分カルーセルで投稿
- 1枚目は「あなたは何タイプ？」の表紙、最後に「診断はプロフィールのリンクから」
- ストーリーにはリンクスタンプで直接URLを貼れる

## アフィリエイト

各アプリの `<script>` 先頭の `AFFILIATE.amazonTag` に AmazonアソシエイトのトラッキングID（例 `xxxx-22`）を入れるだけで、
おすすめ欄のリンクにIDが付き「※本ページはプロモーションを含みます」も自動表示されます。

- 2023年10月からステマ規制があるため、広告リンクを置くページには PR 表記が必須です（自動で出ます）
- Amazonアソシエイトは「審査時にある程度のコンテンツと、申請後180日以内に3件の売上」が条件。アプリが数本たまってから申請がおすすめ
- 先に始めやすいのは もしもアフィリエイト / 楽天アフィリエイト / A8.net
